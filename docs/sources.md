## Verification rule

Do not mark a source compatible until a real query returns inspectable content and extracted links are validated as book-detail pages. HTTP success alone is insufficient. If a source is unavailable or blocks automation, preserve it in the UI as unavailable and provide a direct search link only when its URL is confirmed. Do not circumvent authentication or anti-bot controls.
